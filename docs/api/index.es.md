# Referencia de API

Todo se importa desde el nivel superior: `import doekit as ed`. Las páginas siguientes
se generan automáticamente desde los docstrings del código.

- [Factores y modelo](factors-model.md) — `ContinuousFactor`, `Model`, términos.
- [Diseños](designs.md) — screening, factorial, superficie de respuesta, DSD,
  aleatorios, óptimos, y los criterios de optimalidad.
- [Evaluación](evaluation.md) — eficiencias, potencia, VIF, alias, FDS y gráficas.
- [Análisis y reporte](analysis-report.md) — ajuste lineal, efectos principales, reporte
  HTML y el asesor de diseño.

Para el *cuándo* y el *por qué* de cada método, ver la sección de
[Teoría](../theory/factors-and-coding.md).
