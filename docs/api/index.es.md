# Referencia de API

Todo se importa desde el nivel superior: `import doekit as ed`. Las páginas siguientes
se generan automáticamente desde los docstrings del código.

- [Factores y modelo](factors-model.md) — factores (incl. mezcla), `Model`, términos.
- [Diseños](designs.md) — screening, factorial, RSM, DSD, mezcla, split-plot,
  aleatorios, óptimos y criterios de optimalidad.
- [Evaluación](evaluation.md) — eficiencias, potencia, VIF, alias, FDS y gráficas.
- [Análisis y reporte](analysis-report.md) — ajuste OLS/mixtos, asesor, `Experiment`,
  DoE secuencial, reporte HTML y exportación.

Para el *cuándo* y el *por qué* de cada método, ver la sección de
[Teoría](../theory/factors-and-coding.md).
