Todo se importa desde el nivel superior: `import doekit as ed`. Las páginas siguientes
se generan automáticamente desde los docstrings del código.

- [Factores y modelo](./factors-model.mdx) — factores (incl. mezcla), `Model`, términos.
- [Diseños](./designs.mdx) — screening, factorial, RSM, DSD, mezcla, split-plot,
  aleatorios, óptimos y criterios de optimalidad.
- [Evaluación](./evaluation.mdx) — eficiencias, potencia, VIF, alias, FDS y gráficas.
- [Análisis y reporte](./analysis-report.mdx) — ajuste OLS/mixtos, asesor, `Experiment`,
  DoE secuencial, reporte HTML y exportación.

Para el _cuándo_ y el _por qué_ de cada método, ver la sección de
[Teoría](../theory/factors-and-coding.mdx).
