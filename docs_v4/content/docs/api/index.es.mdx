Todo se importa desde el nivel superior: `import doekit as ed`. Las páginas siguientes
se generan automáticamente desde los docstrings del código.

- [Factores y modelo](factors-model) — factores (incl. mezcla), `Model`, términos.
- [Diseños](designs) — screening, factorial, RSM, DSD, mezcla, split-plot,
  aleatorios, óptimos y criterios de optimalidad.
- [Evaluación](evaluation) — eficiencias, potencia, VIF, alias, FDS y gráficas.
- [Análisis y reporte](analysis-report) — ajuste OLS/mixtos, asesor, `Experiment`,
  DoE secuencial, reporte HTML y exportación.

Para el *cuándo* y el *por qué* de cada método, ver la sección de
[Teoría](../theory/factors-and-coding).
